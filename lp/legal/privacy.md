# プライバシーポリシー

最終更新日: 2026年9月30日

takoikatakotako（以下「当方」といいます）は、スマートフォン向けアプリケーションの開発を行っております。本アプリ「シン反応機構」（英語名 Reaction、以下「本アプリ」といいます）をご利用いただくにあたり、以下のプライバシーポリシーをご確認ください。本アプリをご利用いただいた場合、本プライバシーポリシーに同意いただいたものとみなします。

本アプリは、アカウント登録を必要とせず、氏名・メールアドレス・電話番号などの個人を直接特定する情報をユーザーに入力していただくことはありません。収集した情報は、サービスの提供および改善のために使用されます。

## 1. サポート

本アプリでは、サポートのため、デバイスの種類やOSのバージョンといった情報を取得する場合があります。これらの情報は、不具合が発生した際の原因究明に役立てるためです。

## 2. クラッシュ情報の収集

本アプリ（iOS 版・Android 版）では、不具合の原因究明のため、Google が提供する Firebase Crashlytics を利用してクラッシュ情報を収集します。

収集する場合がある情報は以下のとおりです。

- エラー情報・クラッシュ情報（発生箇所、スタックトレース）
- デバイスの機種
- OSバージョン
- アプリのバージョン
- 端末に固有ではないインストール識別子

クラッシュ情報は、アプリが異常終了した際に記録され、次回起動時に送信されます。

## 3. データ解析

本アプリの iOS 版では、アプリの利便性向上のため、Google が提供する Firebase Analytics を利用してアクセス解析を行います。

収集する場合がある情報は以下のとおりです。

- アプリの利用状況（画面の表示、操作の回数など）
- デバイス情報
- OSバージョン
- おおよその地域

Android 版では Firebase Analytics を利用していません。

これらの情報は、サービスの品質向上およびユーザー体験の改善を目的として使用されます。Firebase における情報の取り扱いについては、[Google プライバシーポリシー](https://policies.google.com/privacy)をご確認ください。

## 4. プッシュ通知

本アプリの iOS 版では、お知らせの配信のため、Google が提供する Firebase Cloud Messaging を利用します。通知の送信に必要な端末のトークンを取得しますが、これは個人を特定する情報ではありません。

プッシュ通知の受信可否は、端末の設定からいつでも変更できます。Android 版ではプッシュ通知を利用していません。

## 5. アプリ内課金

本アプリの iOS 版では、Apple が提供する App Store の課金機能（StoreKit）を利用したアプリ内課金を行います。

**決済に関する情報は Apple が処理し、当方はクレジットカード番号などの決済情報を取得しません。** 当方が受け取るのは、購入が完了したかどうかの情報のみです。

## 6. 通信について

本アプリは、反応機構のデータおよび画像を当方のサーバー（Amazon Web Services）から取得します。この通信の際、サーバー側のアクセスログに IP アドレスおよび接続日時が記録される場合があります。これらは不正アクセスの検知および障害対応の目的でのみ使用します。

## 7. 広告について

**本アプリは広告を表示しません。** 広告識別子（IDFA / 広告 ID）の取得および利用も行いません。

## 8. 第三者への提供

当方は、法令に基づく場合を除き、収集した情報を第三者に販売・譲渡することはありません。

本アプリが利用する外部サービスプロバイダは以下のとおりです。

- Google（Firebase Crashlytics / Firebase Analytics / Firebase Cloud Messaging）
  - プライバシーポリシー: https://policies.google.com/privacy
- Apple（App Store の課金機能。iOS 版のみ）
  - プライバシーポリシー: https://www.apple.com/legal/privacy/
- Amazon Web Services（データおよび画像の配信）
  - プライバシーポリシー: https://aws.amazon.com/jp/privacy/

ユーザーは、本アプリを使用することで、外部サービスプロバイダによる情報の収集および使用に同意したものとみなされます。

## 9. 免責事項

当方は、合理的な範囲内でサポートを提供しますが、利用者が本アプリを利用して生じた損害に関して、当方は責任を負わないものとします。

## 10. 本ポリシーの変更

当方は、必要に応じて本プライバシーポリシーを変更することがあります。変更後の内容は本ページに掲載した時点で効力を生じるものとします。

本サービスの利用条件については、別途定める[利用規約](/terms.html)をご確認ください。
