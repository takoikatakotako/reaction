# プライバシーポリシー

最終更新日: 2026年11月25日

takoikatakotako（以下「当方」といいます）は、スマートフォン向けアプリケーションの開発を行っております。本アプリ「シン反応機構」（英語名 Reaction、以下「本アプリ」といいます）をご利用いただくにあたり、以下のプライバシーポリシーをご確認ください。本アプリをご利用いただいた場合、本プライバシーポリシーに同意いただいたものとみなします。

本アプリは、アカウント登録を必要とせず、アプリ内で氏名・メールアドレス・電話番号などの個人を直接特定する情報をユーザーに入力していただくことはありません。ただし、お問い合わせフォームをご利用いただく場合は、返信のためにメールアドレスをご入力いただくことがあります（「2. お問い合わせ」参照）。収集した情報は、サービスの提供および改善のために使用されます。

## 1. サポート

本アプリでは、サポートのため、デバイスの種類やOSのバージョンといった情報を取得する場合があります。これらの情報は、不具合が発生した際の原因究明に役立てるためです。

## 2. お問い合わせ

本アプリおよび本ページからは、Google が提供する Google フォームを利用したお問い合わせフォームをご案内しています。

お問い合わせフォームで取得する場合がある情報は以下のとおりです。

- お問い合わせの内容としてご入力いただいた情報
- 返信先のメールアドレス（返信が必要な場合のみ）

これらの情報は、お問い合わせへの回答および不具合の調査のためにのみ使用し、それ以外の目的には使用しません。ご入力いただいた情報は Google のサービス上に保管され、当方のみが閲覧します。対応が完了した情報は、必要な期間を過ぎたのち削除します。

お問い合わせの本文には、回答に必要な範囲を超える個人情報を記載しないようお願いします。

## 3. クラッシュ情報の収集

本アプリ（iOS 版・Android 版）では、不具合の原因究明のため、Google が提供する Firebase Crashlytics を利用してクラッシュ情報を収集します。

収集する場合がある情報は以下のとおりです。

- エラー情報・クラッシュ情報（発生箇所、スタックトレース）
- デバイスの機種
- OSバージョン
- アプリのバージョン
- 端末に固有ではないインストール識別子

クラッシュ情報は、アプリが異常終了した際に記録され、次回起動時に送信されます。

## 4. データ解析

本アプリの iOS 版では、アプリの利便性向上のため、Google が提供する Firebase Analytics を利用してアクセス解析を行います。

収集する場合がある情報は以下のとおりです。

- アプリの利用状況（画面の表示、操作の回数など）
- デバイス情報
- OSバージョン
- おおよその地域

Android 版では Firebase Analytics を利用していません。

これらの情報は、サービスの品質向上およびユーザー体験の改善を目的として使用されます。Firebase における情報の取り扱いについては、[Google プライバシーポリシー](https://policies.google.com/privacy)をご確認ください。

## 5. プッシュ通知

本アプリの iOS 版では、お知らせの配信のため、Google が提供する Firebase Cloud Messaging を利用します。

通知の送信には、アプリのインストールごとに Firebase が発行する登録トークンを利用します。このトークンはアプリのインストールを識別する一意の値です。当方はこれを通知の配信にのみ使用し、氏名・メールアドレスなど個人を特定する情報と結び付けることはありません。また、第三者へ提供することもありません。

アプリを削除するか再インストールすると、トークンは無効になるか新しく発行されます。プッシュ通知の受信可否は、端末の設定からいつでも変更できます。Android 版ではプッシュ通知を利用していません。

## 6. アプリ内課金

本アプリの iOS 版では、Apple が提供する App Store の課金機能（StoreKit）を利用したアプリ内課金（有料プラン）を行います。また、購入状況の管理のため、RevenueCat, Inc.（米国）が提供する RevenueCat を利用します。

**決済に関する情報は Apple が処理し、当方および RevenueCat はクレジットカード番号などの決済情報を取得しません。**

RevenueCat を通じて取得・管理する場合がある情報は以下のとおりです。

- 本アプリが自動で発行する匿名のユーザー識別子（氏名やメールアドレス、Apple アカウントとは結び付きません）
- 購入履歴（購入した商品、購入日時、有効期限、無料お試しの利用有無、取引の識別子）
- アプリのバージョン、OS バージョン、端末の言語および国・地域
- 通信時の IP アドレス

これらの情報は、有料プランの機能の提供、購入の復元、不正な購入の防止、および売上の集計のためにのみ使用します。これらの情報は RevenueCat のサーバー（米国）に保管されます。RevenueCat における情報の取り扱いについては、[RevenueCat のプライバシーポリシー](https://www.revenuecat.com/privacy/)をご確認ください。

## 7. 通信について

本アプリは、反応機構のデータおよび画像を当方のサーバー（Amazon Web Services）から取得します。この通信の際、サーバー側のアクセスログに IP アドレスおよび接続日時が記録される場合があります。これらは不正アクセスの検知および障害対応の目的でのみ使用します。

## 8. 広告について

**本アプリは広告を表示しません。** 広告識別子（IDFA / 広告 ID）の取得および利用も行いません。

## 9. 第三者への提供

当方は、法令に基づく場合を除き、収集した情報を第三者に販売・譲渡することはありません。

本アプリが利用する外部サービスプロバイダは以下のとおりです。

- Google（Firebase Crashlytics / Firebase Analytics / Firebase Cloud Messaging / Google フォーム）
  - プライバシーポリシー: https://policies.google.com/privacy
- Apple（App Store の課金機能。iOS 版のみ）
  - プライバシーポリシー: https://www.apple.com/legal/privacy/
- RevenueCat（アプリ内課金の購入状況の管理。iOS 版のみ）
  - プライバシーポリシー: https://www.revenuecat.com/privacy/
- Amazon Web Services（データおよび画像の配信）
  - プライバシーポリシー: https://aws.amazon.com/jp/privacy/

ユーザーは、本アプリを使用することで、外部サービスプロバイダによる情報の収集および使用に同意したものとみなされます。
